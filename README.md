# meeting-room-booking · 会议室预约系统

一个全栈练习项目：会议室的查询、预约、时间冲突校验与取消，支持多用户登录。

## 技术栈

- 后端：Node.js + TypeScript + Express + MySQL 8
- 前端：Vue3 + Element Plus
- 基础设施：Docker / Docker Compose、Nginx

## 功能规划

- [x] 项目初始化
- [ ] 用户注册 / 登录（JWT 鉴权）
- [ ] 会议室管理（CRUD + 权限控制）
- [ ] 会议室预约与时间冲突校验（事务 + 锁）
- [ ] 我的预约（分页 / 取消）
- [ ] Docker Compose 一键启动
- [ ] 前端界面
- [ ] 部署上线
